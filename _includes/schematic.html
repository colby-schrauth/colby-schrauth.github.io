{%- comment -%} The schematic: stages in order, as a row of joined boxes (see STYLE.md). Usage: {% include schematic.html id="ladder" %}, with page.schematics.ladder defined in front matter. Each stage has a `name` and `nodes`; a node is "Text" or "Text | small note". Stages whose node text is listed in `lit` are drawn in brass. `numbered: true` puts a small step number above each name. Optional `views` (like the matrix): tabs that swap each stage's text; each view has a `label` and `cells` (one `eg` per stage, in order). {%- endcomment -%} {%- assign s = page.schematics[include.id] -%}
